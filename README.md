# hofmann-scanner-releases
Access point for Obtainium to get Hofmann Scanner app

Obtainium enables the user to easily update the application without having to reinstall the newest version of the APK manually.
To do this:
1. Install Obtainium on your phone
2. Add new source
3. Input the GitHub URL of this project (until ../hofmann-scanner-releases)
4. Save\n
Now when a new version of the project is released, you can update the app by going into Obtainium, pressing the app, scrolling  down to reload if newest version isnt displayed yet, and then just press Update.

If you would prefer to download the app by APK manually, do this:
1. Download APK on either phone directly or PC
2. If downloaded on PC, move it onto your phone via either USB transfer or folder sharing.
3. Press the APK and let your download Manager run you through the installation.
4. Done\n
Remember, you'll have to do this every time a new version drops to keep the most up to date version of the app.
